# Русская автономная прошивка `4.3.5_3319` (Modern Slate Dark UI) для Xiaomi Xiaobai Smart Cat Eye M1 (`CMMY18A` / `chuangmi.cateye.ipc018`)

Полностью русифицированная модификация прошивки **`4.3.5_3319`** с современным интерфейсом **Slate Dark**, поддержкой карт памяти **64 / 128 / 256 ГБ (FAT32, кластер 64 КБ)**, работой **полностью без облака Mi Home** (`< 1 мА` во сне, пробуждение по Wi-Fi WoWLAN 24/7) либо **параллельно с Mi Home**, кнопочным пультом и голосовым интеркомом в **Telegram** (включая семейные группы), выгрузкой видео на локальный **NAS / роутер (FTP / WebDAV)**, интеграцией **Home Assistant (MQTT Auto-Discovery)** без аккаунта Xiaomi и локальной веб-панелью **`http://<IP>:8080`**.

---

## 1. Физические кнопки и разъёмы глазка (`CMMY18A`)

> [!IMPORTANT]
> На внутреннем мониторе **Xiaobai Smart Cat Eye M1 (`CMMY18A`) НЕТ отверстия `Reset` под скрепку.** Все действия по включению, пробуждению и принудительной перезагрузке выполняются двумя физическими кнопками корпуса:

| Элемент корпуса | Где находится | Что делает (проверено по `hodor_mcu` `nRF52` + `U-Boot`) |
| :--- | :--- | :--- |
| **Кнопка `Home`** | Под экраном на лицевой панели | • **Короткое нажатие (`<= 1 с`)** — разбудить / погасить экран<br>• **Осторожно!** Удержание одной **`Home` `>= 5 с`** — **сброс к заводским настройкам и отвязка (`Factory Reset`)**! |
| **Кнопка питания `Power`** | На верхнем торце *(при портретной установке `90°` — на боковом торце)* | • **Удержание `~2–3 с`** — штатное включение / выключение питания *(если Linux завис, через `15 с` контроллер `hodor_mcu` принудительно обесточит процессор)* |
| **Комбинация `Power` + `Home`** *(вместе, **БЕЗ USB к ПК**)* | Обе кнопки одновременно | • **Удержание `~4–5 с`** *(без `tf_update.img` на SD)* — **быстрая аппаратная перезагрузка** зависшего устройства (`hodor_mcu` снимает питание SoC на `10 мс` и перезапускает его)<br>• **Удержание `~6–8 с`** *(с `tf_update.img` в корне FAT32 `<= 16 ГБ`)* — **запуск восстановления стоковой прошивки с SD-карты** (`GPIO0_0 = LOW` → U-Boot прошивает `tf_update.img`)<br>• *Важно: при подключённом к ПК кабеле USB эта же комбинация переводит чип в `HiSilicon USB BootROM` (`12D1:D001`), поэтому для SD-восстановления кабель USB нужно отключить!* |
| **Слот MicroSD (TF)** | На боковой грани | Карты от `4 ГБ` до `256 ГБ`, строго **FAT32 с кластером `64 КБ` (MBR `0x0B`)** |
| **Разъём Micro-USB** | На боковой грани | Зарядка `5V / 2A` и подключение к ПК в режиме `USB RNDIS` (`Test Mode`) |
| **Кнопка звонка** | На наружном блоке за дверью | Пробуждает систему, делает снимок/запись и шлёт уведомление |

## 2. Какой из двух вариантов прошивки выбрать?

Подготовлены **две полноценные сборки**, отличающиеся ориентацией внутреннего экрана, сенсора касаний, загрузочных заставок LiteOS и углом записи по умолчанию:

| Вариант | Архив / папка сборки | Когда выбирать | Экран и тачскрин | Записи `.mp4` / `.jpeg` по умолчанию |
| :--- | :--- | :--- | :--- | :--- |
| **Горизонтальная (штатная)** | `xiaobai-m1-4.3.5_3319-landscape.zip` (`out_patch_435_landscape/`) | Стандартная горизонтальная установка глазка и монитора (подходит большинству пользователей) | **`854×480`** (горизонтальный Slate Dark UI + горизонтальные заставки `800×450`) | **`1920×1080` (`16:9`, `CAM_ROTATE=0`)** |
| **Вертикальная (`90°` по часовой)** | `xiaobai-m1-4.3.5_3319-portrait.zip` (`out_patch_435_portrait/`) | Узкое посадочное место на двери, когда экран и наружная камера повернуты на **90° по часовой стрелке** | **`480×854`** (портретный Slate Dark UI + вертикальные заставки `450×800`) | **`1080×1920` (`9:16`, `CAM_ROTATE=90`)** |

> [!TIP]
> Если внутренний монитор установлен горизонтально (`landscape`), а наружную камеру пришлось повернуть боком (или наоборот), перепрошивать ничего не нужно — угол поворота камеры и видео (`0° / 90° / 270° / 180°`) переключается на лету одной кнопкой в Telegram или в веб-панели!

## 3. Что входит в состав прошивки

1. **100% русификация экрана, озвучки и загрузочных заставок + 4 кнопки на главном экране:**
   - Русские языковые пакеты (`zh.lang`, `en.lang`), кириллические шрифты `.ubf` с пропорциональными метриками и интерфейс **Slate Dark** (`#0D131F` / `#162032`, 0 обрезанных надписей).
   - **Нижняя 4-кнопочная док-панель главного экрана (`[ Снимок | Запись | Записи | Настройки ]`):**
     - **«Снимок»** — сохраняет текущий кадр с активной камеры в `/app/sd/snapshots/`, отправляет в Home Assistant (`MQTT`) и в Telegram *(работает во время активного видеопревью / после звонка)*;
     - **«Запись»** — записывает 10-секундный ролик `.mp4` (`H.265` + `G.711 A-law`) со звуком и вертикальной/горизонтальной миниатюрой на MicroSD, регистрирует его в разделе **«Записи»** на экране глазка, выгружает на NAS и сразу присылает в **Telegram** и **Home Assistant** (также доступно по кнопке `🎬 Запись 10с` в Telegram и в веб-портале);
     - **«Записи»** и **«Настройки»** — архив видео на карте памяти и меню настроек.
   - Заменены все китайские заставки ранней загрузки Huawei LiteOS в `mtd5` (*«Умный видеоглазок Xiaomi Cat Eye M1»*, *«Обновление системы...»*, *«Нет связи с камерой»*) и голосовые подсказки (`ru-RU-DmitryNeural`).
   - В меню **«Настройки → О системе → ПО / IP»** прямо на экране отображается текущий живой **IP-адрес Wi-Fi**.
   - Встроенная защита от цикла перезагрузок и сбор краш-логов в `/app/sd/.eye_crashlogs/`.
2. **Поддержка карт MicroSD 64 / 128 / 256 ГБ (FAT32, кластер `64 КБ`):**
   - Исправлено штатное форматирование `HI_FSTOOL_Format` (раздел MBR `0x0B Win95 FAT32`, кластер `64 КБ`): глазок сам форматирует большие карты прямо из меню, и они без проблем читаются в Windows.
3. **Точное местное время на экране и штампе видео (`EET-2` .. `VLAT-10`):**
   - Из `main_app` удалены все 7 зашитых китайских сдвигов `UTC+8` (`±28800 с`), а системные и аппаратные часы `rtc0` переведены на местное время (`hwclock -l`, `cm_time_sync` + `ntpd`).
4. **Два режима работы (`MI_CLOUD_ENABLE` в `eye.conf`):**
   - **`MI_CLOUD_ENABLE=0` (по умолчанию — полная автономия, `< 1 мА` во сне):** отключены китайские облачные сервисы и TUTK P2P `miio_stream`, исправлено зависание живого экрана при звонке в автономном режиме, прямое подключение к Wi-Fi без QR-кодов, аппаратный keepalive Wi-Fi чипа (`HEARTBEAT_SERVERS="auto:9999"`, `< 0.35 мА·ч/сутки`) для 24/7 пробуждения по **WoWLAN** даже через часы и сутки сна.
   - **`MI_CLOUD_ENABLE=1` (параллельно с Mi Home):** штатное приложение Mi Home продолжает работать, а поверх него одновременно работают русский интерфейс, правильный часовой пояс, Telegram, NAS и Home Assistant.
5. **Кнопочный пульт Telegram + живой голосовой интерком + семейная группа:**
   - При звонке/движении приходят мгновенное фото с кнопками ответа и видео `.mp4` со звуком.
   - Зажмите **🎙 микрофон** в чате бота и отправьте обычное голосовое сообщение — встроенный декодер `libopus` озвучит ваш голос через динамик за дверью (с кнопкой сохранения в слот *«Своя фраза»*).
   - Опциональный круглосуточный демон для роутера **OpenWrt (`openwrt/`)**: мгновенный отклик за `< 0.2 с` и пробуждение спящего глазка по **WoWLAN**.
6. **NAS / роутер (`BACKUP_URL`) + Home Assistant (`MQTT Auto-Discovery`, 10 объектов) + Веб-портал (`http://<IP>:8080`).**

## 4. Подготовка карты памяти MicroSD

> [!CAUTION]
> **Главное правило SD-карты для `CMMY18A`:** штатный драйвер `main_app` (`FSCK_FAT_Read`) **отвергает любую карту FAT32, если размер кластера не равен `64 КБ` (`65536 байт`)**, а загрузчик `U-Boot` не видит файлы обновления на разделах `> 32 ГБ`.
> - Карты **4–32 ГБ**: форматируйте в **FAT32**, размер кластера **`64 КБ` (`65536`)**, таблица разделов **MBR** (НЕ GPT!).
> - Карты **64 / 128 / 256 ГБ**: для первичной прошивки (и аварийного восстановления) используйте наш безопасный скрипт **`prepare_sd_16gb.bat`** из архива — он создаст на выбранной вами USB-карте раздел `16 ГБ` (`FAT32`, кластер `64 КБ`, `MBR 0x0B`), запишет файлы и проверит MD5. После установки прошивки карту можно в 1 клик расширить на весь объём `64–256 ГБ` из меню самого глазка (**Настройки → MicroSD → Форматировать**) либо скриптом `expand_sd_full_64k.py`.

### Как должна выглядеть карта MicroSD перед прошивкой
1. Убедитесь, что в корне карты памяти **НЕТ** файла `tf_update.img`!
2. В корне карты памяти создайте папку **`patch_435`** и скопируйте в неё **4 файла** из выбранного варианта (`landscape` или `portrait`):
   - `media_app_zip.bin`
   - `uImage.bin`
   - `rootfs.squashfs`
   - `MD5SUMS.txt`
3. Скопируйте **`eye.conf.example`** в корень карты памяти и переименуйте в **`eye.conf`** (настроить Wi-Fi и Telegram можно сразу или позже через браузер).
4. Создайте в корне карты пустой файл с точным именем **`IPC018_TESTMODE.file`** *(проверьте, чтобы Windows не добавила скрытое `.txt`!)*.

```text
SD:/
├── IPC018_TESTMODE.file       (пустой файл 0 байт для входа в режим USB RNDIS)
├── eye.conf                   (ваши настройки Wi-Fi / Telegram / часового пояса / HA / NAS)
└── patch_435/
    ├── MD5SUMS.txt
    ├── media_app_zip.bin
    ├── uImage.bin
    └── rootfs.squashfs
```

## 5. Пошаговая первичная установка прошивки (по USB-кабелю)

> [!IMPORTANT]
> Перед прошивкой зарядите внутренний блок хотя бы до **40–50%** и используйте кабель Micro-USB **с передачей данных** (не «только зарядка»). Шлейф наружной камеры во время прошивки подключать не обязательно.

### Шаг 1. Вход в `Test Mode` и подключение по USB RNDIS

> [!IMPORTANT]
> **Отличие стоковой прошивки от нашей `4.3.5_3319`:**
> - На **заводской (стоковой)** прошивке (`4.0.9_2313` или стоковая `4.3.5_3319`) просто положить `IPC018_TESTMODE.file` и перезагрузиться **недостаточно** — сток проверяет этот файл только при секретной комбинации из **5 касаний** в меню **«Настройки»**! *(Для этого при первичной прошивке шлейф наружной камеры должен быть подключён, чтобы на экране были кнопки меню.)*
> - На **уже установленной нашей** прошивке `4.3.5_3319` патч в `/etc/init.d/S00devs` проверяет `IPC018_TESTMODE.file` автоматически при каждом старте — тыкать экран больше не нужно.

#### Вариант 1 — Первичная установка со стоковой (заводской) прошивки
1. **USB-кабель НЕ подключайте!** Вставьте подготовленную карту MicroSD (с `IPC018_TESTMODE.file` и папкой `patch_435/`) в слот монитора и включите глазок в обычном режиме (кнопкой **`Home`** или **`Power`**).
2. На экране нажмите **«Настройки»** (шестерёнка) и стрелкой **`>`** в правом верхнем углу перейдите на **3-ю (последнюю) страницу «О системе»**, где сверху расположены 3 информационные строки:
   - **Строка 1:** `MAC` (слева) | `XX:XX:XX:XX:XX:XX` (справа)
   - **Строка 2:** `Версия ПО` (слева) | `4.x.x` (справа)
   - **Строка 3:** `Заряд батареи`
3. **Быстро (нужно уложиться строго в `4 секунды` от 1-го до 5-го касания!) нажмите 5 раз по этим трём строкам «зигзагом»:**
   ```text
   1) Строка 1 (MAC)           — ЛЕВАЯ половина
   2) Строка 1 (MAC)           — ПРАВАЯ половина
   3) Строка 2 (Версия ПО)     — ЛЕВАЯ половина
   4) Строка 2 (Версия ПО)     — ПРАВАЯ половина
   5) Строка 3 (Заряд батареи) — любое место строки
   ```
4. Если `IPC018_TESTMODE.file` лежит в корне карты и вы уложились в 4 секунды, сразу откроется **скрытое инженерное меню** (`猫眼测试项目` / `Тест устройства`).
5. В нижнем ряду инженерного меню (6 кнопок: `SCREEN` | `LEFT SPK` | `RIGHT SPK` | **`TEST MODE`** | `VNET OFF` | `RESET`) нажмите 4-ю кнопку слева — **`TEST MODE`**.
   - Глазок выполнит `/app/bin/factory set test 1; reboot` и **сам перезагрузится** в режим `Linux Test Mode`.
   - *(Кнопку `VNET OFF` нажимать не нужно — на стоке без `Test Mode` она не запускает `telnetd`.)*
6. Дождитесь после перезагрузки ровного **пустого подсвеченного экрана** (`~10–12 секунд`, **USB всё ещё отключён!**).

#### Вариант 2 — Повторный вход в `Test Mode` (если наша `4.3.5_3319` уже установлена)
1. **НЕ подключайте USB-кабель заранее!** Вставьте карту MicroSD с файлом `IPC018_TESTMODE.file`.
2. Перезапустите глазок **строго от батареи** (через меню/веб-панель, выкл/вкл кнопкой **`Power` ~2–3 с**, либо аппаратной перезагрузкой **`Power` + `Home` ~4–5 с** без `tf_update.img`) и подождите **~10–12 секунд** до ровного пустого подсвеченного экрана.

---

#### Подключение USB RNDIS к ПК (общее для обоих вариантов)
> [!WARNING]
> **Почему нельзя втыкать USB до загрузки Linux:** если кабель Micro-USB подключён в момент старта/перезагрузки, первичный `BootROM` (`VID_12D1&PID_D001`) на 5 секунд перехватывает USB-контроллер `DWC3`, и драйвер `USB RNDIS` (`VID_1D6B&PID_0104`) после этого не поднимается до новой перезагрузки от батареи.

1. **Только когда экран стал пустым с подсветкой**, подключите кабель Micro-USB к ПК и подождите 2–3 секунды.
2. Запустите **`connect_rndis.bat`** (от имени Администратора) — скрипт настроит драйвер Microsoft USB RNDIS, назначит адаптеру ПК адрес **`192.168.0.2`** и добавит маршрут до глазка **`192.168.0.1`**.
   > [!NOTE]
   > Если ваш домашний роутер тоже использует адрес `192.168.0.1`, на время подключения по USB адрес `192.168.0.1` будет указывать на глазок. **Сразу после завершения прошивки и отключения USB обязательно запустите `cleanup_rndis_route.ps1`**, чтобы вернуть доступ к веб-интерфейсу роутера!

### Шаг 2 (Вариант А — Автоматический, рекомендуется). Бэкап и прошивка в 1 команду
При установленном **Python 3** откройте PowerShell в папке с распакованным архивом и выполните:
```powershell
python install_firmware.py
```
Скрипт автоматически:
1. Скопирует `/lib/*`, `busybox`, `upmtd` и `factory` в оперативную память (`/tmp`).
2. Сохранит **полный побитовый бэкап всех 8 разделов вашей родной флеш-памяти (`mtd0..mtd7`, 16 МБ)** в папку **`SD:/backup_orig/`** (включая уникальные ключи и калибровки вашего экземпляра!).
3. Сверит контрольные суммы **`MD5SUMS.txt`** на карте памяти до записи во флеш.
4. Прошьёт и побайтово проверит (`100%`) `mtd5` (`media_app_zip.bin`), `mtd6` (`uImage.bin`, если отличается) и `mtd7` (`rootfs.squashfs`).
5. Удалит `IPC018_TESTMODE.file`, выставит `factory set test 0` (до перезаписи `mtd7`) и чисто перезагрузит глазок из RAM.

> [!TIP]
> После прошивки отсоедините USB, запустите `cleanup_rndis_route.ps1` и обязательно скопируйте папку **`SD:/backup_orig/`** в надёжное место на компьютере! **Никогда не делитесь файлами `mtd3`/`mtd4` из своего бэкапа** — внутри хранятся уникальные ключи, MAC и серийный номер именно вашего экземпляра.

### Шаг 2 (Вариант Б — Вручную через PuTTY / Telnet, без Python)
1. Подключитесь по **Telnet** к **`192.168.0.1`**, порт **`23`** (логин `root`, пароль `admin`).
2. **Обязательно сделайте полный бэкап родной флеш-памяти (`mtd0..mtd7`):**
   ```sh
   mkdir -p /app/sd/backup_orig
   dd if=/dev/mtd0 of=/app/sd/backup_orig/mtd0_uboot.bin bs=65536
   dd if=/dev/mtd1 of=/app/sd/backup_orig/mtd1_rawparam.bin bs=65536
   dd if=/dev/mtd2 of=/app/sd/backup_orig/mtd2_rawparambak.bin bs=65536
   dd if=/dev/mtd3 of=/app/sd/backup_orig/mtd3_config.bin bs=65536
   dd if=/dev/mtd4 of=/app/sd/backup_orig/mtd4_factory.bin bs=65536
   dd if=/dev/mtd5 of=/app/sd/backup_orig/mtd5_media_app_zip.bin bs=65536
   dd if=/dev/mtd6 of=/app/sd/backup_orig/mtd6_uImage.bin bs=65536
   dd if=/dev/mtd7 of=/app/sd/backup_orig/mtd7_rootfs.squashfs bs=65536
   sync
   ```
3. **Скопируйте системные библиотеки и утилиты в ОЗУ (`/tmp`) и проверьте `MD5SUMS.txt`:**
   ```sh
   mkdir -p /tmp/lib
   cp -a /lib/* /tmp/lib/ 2>/dev/null || true
   cp /bin/busybox /tmp/busybox && cp /app/bin/upmtd /tmp/upmtd && cp /app/bin/factory /tmp/factory
   chmod 755 /tmp/busybox /tmp/upmtd /tmp/factory
   cd /app/sd/patch_435 && /tmp/busybox md5sum -c MD5SUMS.txt
   ```
   Убедитесь, что напротив всех трёх файлов вывелось **`OK`**!
4. **Прошейте `mtd5`, `mtd6`, снимите флаг `Test Mode` и прошейте `mtd7` из RAM:**
   ```sh
   LD_LIBRARY_PATH=/tmp/lib /tmp/upmtd /app/sd/patch_435/media_app_zip.bin /dev/mtd5
   LD_LIBRARY_PATH=/tmp/lib /tmp/upmtd /app/sd/patch_435/uImage.bin /dev/mtd6
   rm -f /app/sd/IPC018_TESTMODE.file /mnt/sdcard/IPC018_TESTMODE.file
   /app/bin/factory set test 0
   LD_LIBRARY_PATH=/tmp/lib /tmp/busybox sync
   LD_LIBRARY_PATH=/tmp/lib /tmp/upmtd /app/sd/patch_435/rootfs.squashfs /dev/mtd7
   ```
   Дождитесь `Verifying kb: ... (100%)` на каждом шаге!
5. **Чистая перезагрузка из RAM:**
   ```sh
   LD_LIBRARY_PATH=/tmp/lib /tmp/busybox sync
   LD_LIBRARY_PATH=/tmp/lib /tmp/busybox umount /app/sd 2>/dev/null || true
   LD_LIBRARY_PATH=/tmp/lib /tmp/busybox reboot -f
   ```
6. Отсоедините USB-кабель и запустите на ПК `cleanup_rndis_route.ps1`.

## 6. Дальнейшие обновления без снятия глазка с двери (OTA через `IPC018_UPDATE.file`)

> [!CAUTION]
> **НИКОГДА не запускайте `upmtd ... /dev/mtd7` вживую по Wi-Fi в обычном рабочем режиме (`test = 0`)!** Пока работают демоны (`eye_daemon.sh`, `main_app`, `perp`), стирание смонтированного `/` приводит к зависанию посреди прошивки.

После того как наша прошивка `4.3.5_3319` уже установлена, любое следующее обновление корневой системы `rootfs.squashfs` (`mtd7`) выполняется безопасно **без USB и без разборки**:
1. Загрузите свежие `rootfs.squashfs` и `MD5SUMS.txt` в `/app/sd/patch_435/` (по Wi-Fi или скопировав на SD-карту).
2. Создайте в корне SD-карты пустой файл-маркер **`IPC018_UPDATE.file`**, выполните `sync` и перезагрузите глазок (`reboot -f` или через веб-панель / Telegram).
3. При старте самый первый скрипт `/etc/init.d/S00devs` (ещё **до** запуска любых демонов!) сам удалит маркер, сверит MD5 `rootfs.squashfs`, прошьёт `/dev/mtd7` целиком из RAM `/tmp`, размонтирует SD и через ~2 минуты глазок вернётся в домашний Wi-Fi уже с новой версией!
4. Также поддерживается маркер **`IPC018_NORMAL.file`** в корне SD — мгновенно сбрасывает `test = 0` и возвращает глазок из `Test Mode` в обычный режим без USB.

## 7. Аварийное восстановление за 2–3 минуты (`tf_update.img`) и выход из зависаний

Загрузчик **U-Boot (`mtd0`)** мы **никогда не трогаем**, поэтому программно «окирпичить» глазок невозможно:

- **Если глазок просто завис или ушёл в цикл перезагрузок (без перепрошивки):** отключите USB и зажмите **`Power` + `Home` вместе на `~4–5 секунд`** (убедившись, что на SD нет `tf_update.img`), затем отпустите — контроллер `hodor_mcu` жёстко перезапустит процессор (`10 мс` снятия питания). *(Либо зажмите одну `Power` на `~2–3 с` и подождите до `15 с` — MCU принудительно обесточит процессор.)*
- **Если нужно восстановить стоковую прошивку `4.0.9_2313` с MicroSD (`tf_update.img`):**
  1. Подготовьте карту памяти MicroSD **объёмом до `16 ГБ`**, `FAT32`, кластер **`64 КБ`**, **MBR `0x0B`** (для карт `64+ ГБ` просто запустите **`prepare_sd_16gb.bat`** из архива восстановления — он временно создаст `16 ГБ` раздел и сам запишет `tf_update.img`).
  2. Скопируйте файл **`tf_update.img`** (заводская сервисная `4.0.9_2313`) в **корень** карты памяти.
  3. **Обязательно отключите USB-кабель от ПК!** *(Если зажать `Power` + `Home` с подключённым к ПК USB, процессор уйдёт в `HiSilicon USB BootROM` `12D1:D001`, а не в чтение SD-карты!)*
  4. Вставьте карту в глазок и **зажмите ОБЕ кнопки `Power` + `Home` одновременно на `6–8 секунд`**, затем отпустите *(на `~4-й` с контроллер `hodor_mcu` перезапустит процессор и выставит `GPIO0_0 = LOW`, а за оставшиеся `2–4 с` загрузчик U-Boot успеет стартовать и подхватить `tf_update.img`; на обычном включении одной `Power` загрузчик `tf_update.img` пропускает!)*.
  5. Подождите **`~2–3 минуты`** — U-Boot проверит подпись Ed25519 у `tf_update.img`, восстановит `rawparam`, `mtd5`, `mtd6`, `mtd7` (сохранив `u-boot`, `config` и `factory`) и перезагрузится.
  6. **Удалите `tf_update.img` с карты после восстановления**, чтобы будущие аппаратные перезагрузки `Power` + `Home` не откатили прошивку снова.
  7. *(Учтите: заводская `4.0.9_2313` сама по себе не читает `IPC018_TESTMODE.file` при загрузке — если в `mtd4` стоял `test=0`, войдите в `Test Mode` через 5-таповый зигзаг из **Варианта 1** раздела 5, предварительно подключив шлейф камеры, а если `test=1` уже стоял — он сохранится и глазок сам загрузится в `Test Mode`! Подробнее см. `RECOVERY_RU.md`.)*

## 8. Настройка `eye.conf` (без перепрошивки!)

Все функции настраиваются в файле **`eye.conf`** в корне MicroSD (кодировка UTF-8) либо прямо в браузере на **`http://<IP_глазка>:8080`**.

### 8.1. Wi-Fi, часовой пояс и режим работы с облаком
```ini
WIFI_SSID="Имя_вашего_WiFi_2.4GHz"
WIFI_PASS="Пароль_WiFi"

# 0 = Полная автономия без серверов Xiaomi (< 1 мА во сне, живой IP в меню «О системе»)
# 1 = Параллельная работа со штатным приложением Mi Home
MI_CLOUD_ENABLE=0

# Часовой пояс (в POSIX знак минус в MSK-3 означает UTC+3 — это не опечатка!)
TZ="MSK-3"

# Аппаратный keepalive чипа Wi-Fi (50 с, < 0.35 мА·ч/сутки), чтобы роутер не разрывал связь через 5 мин сна:
HEARTBEAT_SERVERS="auto:9999"
```

### 8.2. Telegram-пульт, голосовой интерком и Семейная группа
1. Создайте бота через **`@BotFather`** (`/newbot`) → скопируйте токен в `TG_BOT_TOKEN`.
2. **Для всей семьи (рекомендуется):** создайте закрытую группу в Telegram, добавьте туда родных и бота, **назначьте бота Администратором** (чтобы он видел голосовые `🎙` и нижние кнопки без отключения `Group Privacy`), затем напишите `/id` — бот вернёт ID группы вида `-1001234567890`.
3. Впишите в `eye.conf`:
```ini
TG_BOT_TOKEN="123456789:AAH..."
TG_CHAT_ID="-1001234567890"   # Или личный ID, или несколько ID через запятую
TG_SEND_VIDEO=1               # 1 = присылать видео .mp4 со звуком (H.265 + G.711A)
TG_POLL_ON_DEVICE=1           # Поставьте 0, если используете круглосуточного бота на роутере OpenWrt!
```

### 8.3. Локальный архив на NAS / роутер (`BACKUP_URL`)
```ini
# FTP / FTPS:
BACKUP_URL="ftp://user:pass@192.168.1.1/usb1/cateye/"
# Или WebDAV HTTP / HTTPS:
# BACKUP_URL="http://user:pass@192.168.1.10:5005/cateye/"
```

### 8.4. Home Assistant (`MQTT Auto-Discovery`, без аккаунта Xiaomi)
По умолчанию `MQTT_ENABLE=0` (`0 мА` расхода). Включается в карточке **`🏠 Home Assistant`** веб-портала `http://<IP>:8080` либо в `eye.conf`:
```ini
MQTT_ENABLE=1
MQTT_HOST="192.168.1.10"
MQTT_PORT=1883
MQTT_USER="mqtt_user"
MQTT_PASS="mqtt_pass"
MQTT_PREFIX="xiaobai_m1"
```
В **Home Assistant → Устройства и службы → MQTT** автоматически появятся все **10 объектов**: камера последнего снимка (`snapshot`), датчики звонка / движения / стояния (`bell`, `motion`, `stay` — стартуют в `OFF`, боевые тревоги без `retain`), последнее событие, состояние (`awake`/`sleep`), заряд `%`, напряжение АКБ `В`, сигнал Wi-Fi `dBm` и MicroSD.

## 9. Веб-панель управления (`http://<IP>:8080`)

Когда глазок бодрствует (после нажатия `Home`/`Power`, звонка или пробуждения из Telegram), откройте в браузере **`http://<IP_глазка>:8080`**:
- живой видеопоток **MJPEG**, снимки (с галереей **`/snapshots/`**) и запуск ручной записи **`🎬 Запись 10с`** прямо из браузера;
- просмотр и скачивание записей с MicroSD по датам;
- запись голосового ответа с микрофона браузера или загрузка аудио в слот *«Своя фраза»*;
- переключение PIR, задержки стояния, ИК-подсветки, WDR, LDC, поворота камеры (`0°/90°/180°/270°`), часового пояса, «Тихого часа», MQTT и редактирование `eye.conf` с проверкой синтаксиса.
