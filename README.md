# Xiaomi / IMILAB Xiaobai Smart Cat Eye M1 (`CMMY18A` / `chuangmi.cateye.ipc018`) — Autonomous Russian Firmware `4.3.5_3319`

Полностью русифицированная, автономная и открытая доработка прошивки **`4.3.5_3319`** для умного видеоглазка **Xiaomi Xiaobai Smart Cat Eye M1 (`CMMY18A` / `chuangmi.cateye.ipc018`)** в двух готовых вариантах — **Горизонтальном (`854×480`)** и **Вертикальном (`480×854`, поворот `90°`)**.

> Работает **полностью без облака Mi Home** (`< 1 мА` в глубоком сне + пробуждение по Wi-Fi WoWLAN 24/7) **либо параллельно со штатным Mi Home** (`MI_CLOUD_ENABLE=1`).

---

## Главные возможности

- **Современный русский интерфейс Slate Dark UI** (`1:1` перерисованные ассеты, кириллические шрифты `.ubf`, русские заставки ранней загрузки Huawei LiteOS `mtd5` и мужская озвучка `ru-RU-DmitryNeural`).
- **4-кнопочная нижняя панель главного экрана (`[ Снимок | Запись | Записи | Настройки ]`)**:
  - **Снимок** — сохраняет кадр в `/app/sd/snapshots/`, отправляет в Telegram и Home Assistant;
  - **Запись** — записывает 10-секундный ролик `H.265 + G.711 A-law` со звуком на MicroSD, регистрирует его в альбоме «Записи» на экране, копирует на NAS и отправляет в Telegram и Home Assistant;
  - **О системе → ПО / IP** показывает живой IP-адрес Wi-Fi прямо на экране глазка.
- **Поддержка MicroSD 64 / 128 / 256 ГБ (FAT32, кластер `64 КБ`, MBR `0x0B`)** прямо из меню глазка + безопасный скрипт расширения `tools/expand_sd_full_64k.py`.
- **Точное местное время** (удалены все 7 китайских сдвигов `UTC+8` в `main_app`, часовые пояса `EET-2 .. VLAT-10` переключаются в 1 клик).
- **Кнопочный пульт Telegram + живой голосовой интерком (`🎙` → внешний динамик через встроенный `libopus`)** + поддержка закрытых семейных групп (`-100...`) + опциональный 24/7 демон для роутера **OpenWrt** (`openwrt/`).
- **Home Assistant (`MQTT Auto-Discovery`, 10 объектов, `0 мА` во сне)** — камера последнего кадра, датчики звонка / движения / стояния, статус `awake`/`sleep`, батарея `%` и реальное напряжение `В`, Wi-Fi `dBm`, MicroSD.
- **Локальный бэкап архива на NAS / роутер (`FTP / FTPS / WebDAV`)** + **Web-портал `http://<IP>:8080`** (живой MJPEG, галерея `/snapshots/`, запись `10с`, голосовой ответ с микрофона браузера, настройка NVRAM и `eye.conf`).
- **Безопасные OTA-обновления по Wi-Fi** без снятия с двери (`tools/ota_update_wifi.py` → `IPC018_UPDATE.file` в `S00devs`).
- **Загрузчик `u-boot` (`mtd0`) и заводские калибровки (`mtd1..mtd4`) никогда не затрагиваются** — программно «окирпичить» устройство невозможно, аварийный откат с SD-карты (`tf_update.img`) занимает ~2 минуты.

## Физические кнопки корпуса (`CMMY18A`) и вход в `Test Mode`

На внутреннем мониторе **НЕТ отверстия Reset под скрепку** — управление выполняется двумя физическими кнопками:

| Кнопка / комбинация | Расположение | Действие (проверено по прошивке контроллера `hodor_mcu` + `U-Boot`) |
| :--- | :--- | :--- |
| **`Home`** | Лицевая панель под экраном | • Короткое нажатие (`<= 1 с`) — разбудить / выключить экран<br>• **Осторожно!** Удержание одной **`Home` `>= 5 с`** — **сброс к заводским настройкам / отвязка** (`Factory Reset`)! |
| **`Power`** | Верхний торец *(при портретной установке `90°` — боковой торец)* | • Удержание `~2–3 с` — штатное включение / выключение *(если Linux завис, через `15 с` MCU принудительно обесточит процессор)* |
| **`Power` + `Home`** *(вместе, **БЕЗ USB к ПК**)* | Обе кнопки одновременно | • **Удержание `~4–5 с`** (без `tf_update.img` на SD) — **мгновенная аппаратная перезагрузка** зависшего устройства (MCU жёстко снимает питание SoC на `10 мс`)<br>• **Удержание `~6–8 с`** (с `tf_update.img` в корне FAT32 `<= 16 ГБ`) — **аварийное восстановление стока с SD-карты** (`GPIO0_0 = LOW` → `U-Boot` прошивает `tf_update.img`)<br>• *С подключённым к ПК кабелем USB эта же комбинация переводит чип в `USB BootROM` (`12D1:D001`), поэтому для SD-восстановления USB должен быть отключён!* |

> **Первичный вход в `Test Mode` (USB RNDIS) со стоковой прошивки:** положите пустой `IPC018_TESTMODE.file` в корень SD-карты → откройте **Настройки → 3-я страница («О системе»)** → за **`<= 4 с`** нажмите 5 раз зигзагом (`Строка 1 (MAC) лево → право → Строка 2 (ПО) лево → право → Строка 3 (Батарея)`) → в инженерном меню нажмите **`TEST MODE`** → дождитесь пустого подсвеченного экрана (`~10–12 с` **без USB**), и только потом подключайте Micro-USB. *(После установки нашей `4.3.5_3319` вход по `IPC018_TESTMODE.file` работает автоматически при перезагрузке через `S00devs`.)*

## Структура репозитория

- `eye_addon/` — автономная подсистема `/app/eye/` (демоны, Telegram, MQTT Auto-Discovery, веб-портал `index.html` + `api.cgi` + `stream.cgi`).
- `openwrt/` — круглосуточный бот `eye_openwrt_bot.sh`, cron `eye_keepalive.sh`, init-скрипт `procd` и скрипт выкладки `deploy_openwrt.ps1`.
- `src/` — исходники статических ARM Cortex-A7 утилит `eye_tool.c` (MP4 mux/rot, JPEG rot/scale, MQTT, Opus→G.711A, WoWLAN UDP), `eye_snap.c` и `stb_image_write.h`.
- `builder/` — воспроизводимый пайплайн сборки прошивок `4.3.5_3319` (`build_patch_435.py`, `pack_435_wsl.sh`, генераторы шрифтов `.ubf`, локализации `.lang`, скина Slate Dark, HiGV UI и озвучки).
- `tools/` — утилиты для Windows / Python: `prepare_sd_16gb.bat`, `connect_rndis.bat`, `cleanup_rndis_route.ps1`, `install_firmware.py`, `ota_update_wifi.py`, `expand_sd_full_64k.py`.

## Безопасность и отказ от ответственности

- **Обязательно сохраняйте резервную копию `SD:/backup_orig/` (`mtd0..mtd7`)** после запуска `install_firmware.py` и **никогда не публикуйте `mtd3`, `mtd4` и `eye.conf`** — в них хранятся уникальные ключи, MAC-адрес, серийный номер и пароли вашего экземпляра.
- Все модификации устанавливаются на ваш страх и риск. Автор и участники сообщества не несут ответственности за повреждение оборудования при нарушении инструкций (в частности, при перезаписи `mtd0..mtd4` или отключении питания во время записи SPI NOR).
