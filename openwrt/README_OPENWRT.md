# Круглосуточный кнопочный пульт Telegram (OpenWrt 24/7) для Xiaobai M1

Этот комплект работает **24/7 на вашем роутере OpenWrt** и превращает Telegram в современный **кнопочный пульт управления глазком** (с цветными акцентными кнопками Telegram Bot API 9.4+ / 10.1+, переключением экранов без спама в чате и закреплённым нижним меню — вводить команды со слэшем `/` вообще не нужно):

- **📸 Живое фото в 1 тап** — будит спящий глазок по Wi-Fi (`< 1 мА` WoWLAN UDP) и присылает вертикальный кадр `1080×1920`.
- **🔊 Голосовой ответ за дверь + живой интерком из Telegram** — мгновенное воспроизведение любой из 4 мужских фраз, а также прямое озвучивание обычных **голосовых сообщений Telegram** (зажмите 🎙 микрофон в чате бота — роутер сам разбудит глазок и воспроизведёт ваш голос посетителю, с возможностью сохранить запись в слот «Своя фраза»!).
- **🎞 Видеоархив MicroSD** — просмотр списка последних записей на карте памяти и скачивание выбранного вертикального `.mp4` прямо в чат Telegram.
- **🛡 Датчик движения PIR, ИК-ночь, WDR, звук и питание** — переключение всех скрытых аппаратных настроек (`mortox` NVRAM) прямо кнопками меню.
- **📋 Копирование локального адреса веб-панели** кнопкой `copy_text` в буфер обмена в 1 нажатие.

## Быстрая установка на роутер OpenWrt

### 1. Зафиксируйте статический IP за глазком
В веб-интерфейсе роутера **LuCI → Сеть → DHCP и DNS → Статические аренды (Static Leases)** привяжите MAC-адрес глазка к постоянному IP (например, `192.168.1.50`).

### 2. Установите `curl` и `socat` на OpenWrt
Подключитесь к роутеру по SSH и выполните:
```sh
# OpenWrt 23.05 / 24.10 (opkg):
opkg update && opkg install curl socat ca-bundle

# OpenWrt 25.12+ (apk):
apk update && apk add curl socat ca-bundle
```
*(Утилита `jsonfilter` уже встроена в любую прошивку OpenWrt).*

### 3. Скопируйте файлы на роутер
Из папки `openwrt/` репозитория скопируйте файлы на роутер (через `scp` или WinSCP):
```powershell
scp openwrt/eye_openwrt_bot.sh root@192.168.1.1:/usr/bin/eye_openwrt_bot.sh
scp openwrt/eye-bot.init       root@192.168.1.1:/etc/init.d/eye-bot
scp openwrt/eye-bot.conf       root@192.168.1.1:/etc/eye-bot.conf
```

### 4. Настройте `/etc/eye-bot.conf` на роутере и `/app/sd/eye.conf` на глазке
1. **Для семейного доступа (рекомендуется):** создайте закрытую группу в Telegram (например, **«🚪 Дверной глазок»**), добавьте туда близких и вашего бота, **выдайте боту права Администратора** (чтобы он видел 🎙 голосовые сообщения и нажатия нижних кнопок без отключения Privacy Mode в `@BotFather`), запустите бота и напишите в группе `/id` — бот пришлёт отрицательный ID группы вида `-100...`. *(Также в `TG_CHAT_ID` можно перечислить несколько ID через запятую: `"11111111, 22222222"`).*
2. На роутере отредактируйте `/etc/eye-bot.conf` (`EYE_IP`, `EYE_BROADCAST`, `TG_BOT_TOKEN`, `TG_CHAT_ID`, и при необходимости `TG_PROXY`).
3. В файле `eye.conf` на карте памяти глазка укажите те же `TG_BOT_TOKEN` и `TG_CHAT_ID`, а также:
   ```ini
   TG_POLL_ON_DEVICE=0
   HEARTBEAT_SERVERS="auto:9999"          # автоподстановка IP вашего роутера (шлюза):9999
   ```
   Тогда при звонке в дверь глазок сам мгновенно пришлёт фото и видео в Telegram, нажатия всех кнопок пульта круглосуточно обрабатывает роутер без конфликта `409 Conflict`, а `HEARTBEAT_SERVERS` шлёт аппаратный keepalive раз в `50 с` силами самого Wi-Fi чипа (`~0.2–0.35 мА·ч/сутки`, `< 1%` за полгода), чтобы `hostapd` (`ap_max_inactivity=300`) не разрывал связь после 5 минут сна и WoWLAN срабатывал 24/7!

### 5. Включите автозапуск сервиса на OpenWrt
На роутере выполните:
```sh
sed -i 's/\r$//' /usr/bin/eye_openwrt_bot.sh /etc/init.d/eye-bot /etc/eye-bot.conf
chmod 755 /usr/bin/eye_openwrt_bot.sh /etc/init.d/eye-bot
chmod 600 /etc/eye-bot.conf
/etc/init.d/eye-bot enable
/etc/init.d/eye-bot start
```
Откройте чат с вашим ботом в Telegram и нажмите любую кнопку внизу экрана (`🎛 Пульт глазка`).
